# Changelog

## 0.1.0

- A Kiki row in the DSH web sidebar: shows Kiki when it runs on this Mac, opens it when it is closed, installs it when it is missing (macOS).
- DSH sessions show up in Kiki as cards: working, needs you, done, error.
- Tools for the model: `kiki_ask`, `kiki_services`, `kiki_query`.
- Offers to hand the DeepSeek key saved in DSH to a Kiki installed from DSH.
